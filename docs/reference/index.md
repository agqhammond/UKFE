## QMED functions

  QMED (median annual maximum flow) estimate from catchment descriptors
- [`QMEDDonEq()`](https://github.com/agqhammond/ukfe/reference/QMEDDonEq.md)
  : QMED donor adjustment
- [`QMEDfseSS()`](https://github.com/agqhammond/ukfe/reference/QMEDfseSS.md)
  : QMED factorial standard error for gauged sites
- [`QMEDLink()`](https://github.com/agqhammond/ukfe/reference/QMEDLink.md)
  : QMED Linking equation
- [`QMED_FEH08()`](https://github.com/agqhammond/ukfe/reference/QMED_FEH08.md)
  : QMED (median annual maximum flow) estimate from catchment
  descriptors using the FEH 2008 method.
- [`DonAdj()`](https://github.com/agqhammond/ukfe/reference/DonAdj.md) :
  Donor adjustment candidates

## Get data functions

Functions for retrieving, importing or viewing data.

- [`GetAM()`](https://github.com/agqhammond/ukfe/reference/GetAM.md) :
  Get an annual maximum sample from the National River Flow Archive
  sites suitable for pooling
- [`GetCDs()`](https://github.com/agqhammond/ukfe/reference/GetCDs.md) :
  Get catchment descriptors from the National River Flow Archive sites
  considered suitable for median annual maximum flow estimation (QMED)
  and pooling.
- [`GetDataEA_QH()`](https://github.com/agqhammond/ukfe/reference/GetDataEA_QH.md)
  : Get flow or level data from the Environment Agency's Hydrology Data
  Explorer
- [`GetDataEA_Rain()`](https://github.com/agqhammond/ukfe/reference/GetDataEA_Rain.md)
  : Get Environment Agency rainfall data (England).
- [`GetDataMetOffice()`](https://github.com/agqhammond/ukfe/reference/GetDataMetOffice.md)
  : Get regional Met Office average temperature or rainfall series
  (monthly, seasonal, and annual).
- [`GetDataNRFA()`](https://github.com/agqhammond/ukfe/reference/GetDataNRFA.md)
  : Get National River Flow Archive data using gauge ID.
- [`GetDataSEPA()`](https://github.com/agqhammond/ukfe/reference/GetDataSEPA.md)
  : Get Scottish Environment Protection Agency (SEPA) Flow, Level, or
  Rainfall data.
- [`GetQMED()`](https://github.com/agqhammond/ukfe/reference/GetQMED.md)
  : QMED from a gauged site suitable for QMED
- [`AMImport()`](https://github.com/agqhammond/ukfe/reference/AMImport.md)
  : Import an annual maximum (AMAX) sample from NRFA peak flow .am files
- [`CDsXML()`](https://github.com/agqhammond/ukfe/reference/CDsXML.md) :
  Import catchment descriptors from .xml files
- [`CDsXML_Legacy()`](https://github.com/agqhammond/ukfe/reference/CDsXML_Legacy.md)
  : Import catchment descriptors from older .xml files

## Datasets

  sites suitable for QMED only, and those for pooling.
- [`PeakFlowData`](https://github.com/agqhammond/ukfe/reference/PeakFlowData.md)
  : National River Flow Archive descriptors and calculated statistics
  for sites suitable for QMED & pooling
- [`ThamesPQ`](https://github.com/agqhammond/ukfe/reference/ThamesPQ.md)
  : Kingston upon Thames daily flow and catchment precipitation
  2000-10-01 to 2015-09-30
- [`UKOutline`](https://github.com/agqhammond/ukfe/reference/UKOutline.md)
  : UK outline
